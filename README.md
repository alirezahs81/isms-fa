# سیستم مدیریت خدمات اینترنتی (ISMS)

سیستم مدیریت فروش و اشتراک سرویس‌های اینترنتی — نسخه فارسی (رابط کاربری RTL)

## ✨ امکانات

- 📊 **داشبورد**: آمار کلی، یادآور تمدید سرویس‌های نزدیک به انقضا (۱۴ روز آینده)، فاکتورهای پرداخت‌نشده
- 👥 **مدیریت مشتریان**: ثبت، ویرایش، جستجو و پروفایل کامل مشتری با سرویس‌ها و فاکتورها
- 📦 **پلن‌های سرویس**: سه دسته — اینترنت (ADSL/TD-LTE)، هاست/دامنه/سرور، لایسنس نرم‌افزار — با دوره‌های ماهانه تا سالانه
- 🖥 **مدیریت سرویس‌ها**: ثبت سرویس، فیلتر وضعیت، تمدید یک‌کلیکی، صدور فاکتور تمدید
- 🧾 **فاکتور و پرداخت**: صدور فاکتور با شماره‌گذاری خودکار، تخفیف، ثبت پرداخت (نقدی، کارت به کارت، درگاه آنلاین، انتقال بانکی)، ابطال فاکتور — وضعیت فاکتور پس از پرداخت کامل به‌صورت خودکار «پرداخت شده» می‌شود
- 📈 **گزارش‌ها**: درآمد ماهانه، مطالبات وصول‌نشده، توزیع سرویس‌ها بر اساس دسته‌بندی
- 👤 **مدیریت کاربران**: ایجاد ادمین/کارمند (مخصوص مدیر سیستم)
- 🔐 **پنل ادمین Django**: مدیریت کامل داده‌ها در `/admin/`

دسترسی فقط برای ادمین/کارمند. رابط کاربری کاملاً فارسی و راست‌چین با فونت وزیرمتن.

## 🛠 تکنولوژی‌ها

- Python 3.15 / Django 6.1
- PostgreSQL 16
- HTML/CSS (بدون فریم‌ورک فرانت)

## 🚀 راه‌اندازی

```bash
# نصب پیش‌نیازها
pip install django psycopg2-binary

# ساخت دیتابیس در PostgreSQL
psql -U postgres -c "CREATE DATABASE isms;"

# تنظیم متغیرهای محیطی (اختیاری — پیش‌فرض: isms/postgres@127.0.0.1:5432)
set ISMS_DB_NAME=isms
set ISMS_DB_USER=postgres
set ISMS_DB_PASSWORD=postgres

# اجرای migrations
python manage.py migrate

# ساخت ادمین
python manage.py createsuperuser

# اجرای سرور
python manage.py runserver
```

سپس مرورگر را باز کنید: `http://127.0.0.1:8000`

## ⚙️ متغیرهای محیطی

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `ISMS_DB_NAME` | `isms` | نام دیتابیس |
| `ISMS_DB_USER` | `postgres` | کاربر دیتابیس |
| `ISMS_DB_PASSWORD` | `postgres` | رمز دیتابیس |
| `ISMS_DB_HOST` | `127.0.0.1` | هاست دیتابیس |
| `ISMS_DB_PORT` | `5432` | پورت دیتابیس |
| `ISMS_DEBUG` | `1` | حالت Debug (در پروژه واقعی `0` بگذارید) |
| `ISMS_SECRET_KEY` | — | کلید امنیتی Django |

## 📁 ساختار پروژه

```
isms/
├── services/     # مشتریان، پلن‌های سرویس، سفارش‌های سرویس
├── invoices/     # فاکتورها و پرداخت‌ها
├── accounts/     # مدیریت کاربران سیستم
├── dashboard/    # داشبورد و گزارش‌ها
├── templates/    # قالب‌های فارسی RTL
└── isms/         # تنظیمات پروژه
```
